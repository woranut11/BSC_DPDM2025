## เนื้อหาที่เรียน📖
### 💡Chapter 1. Introduction (บทนำสู่ Data Mining)
ในยุคที่ข้อมูลเติบโตอย่างรวดเร็วจากระดับ *เทราไบต์ → เพตาไบต์* เรามีข้อมูลจำนวนมหาศาลจากทุกที่ เช่น ธุรกิจออนไลน์, เซ็นเซอร์, โซเชียลมีเดีย, กล้องดิจิทัล, การทดลองทางวิทยาศาสตร์ ฯลฯ แต่ปัญหาคือ
**“เรากำลังจมน้ำในข้อมูล แต่ขาดความรู้ที่นำไปใช้ได้จริง”**
เพียงมีข้อมูลเยอะไม่พอ ต้อง *แปลงข้อมูลเป็นความรู้*
นี่จึงเป็นเหตุผลที่ *Data Mining* เกิดขึ้นเพื่อช่วยให้คอมพิวเตอร์สามารถ “ค้นหารูปแบบ” หรือ “ความรู้ใหม่” จากข้อมูลขนาดใหญ่โดยอัตโนมัติ

### 🔎Chapter 2. Getting to Know Your Data (มาทำความรู้จักกับข้อมูลกันเถอะ)
ก่อนที่เราจะทำ Data Mining หรือวิเคราะห์ข้อมูลอย่างจริงจัง ขั้นตอนแรกที่สำคัญคือ *การทำความเข้าใจกับข้อมูล (Getting to Know Your Data)* เพราะข้อมูลแต่ละแบบมีคุณสมบัติไม่เหมือนกัน การเลือกใช้เทคนิควิเคราะห์จึงต้องเหมาะสมกับชนิดข้อมูลด้วย
บทนี้จึงสอนพื้นฐานสำคัญ ได้แก่
* ประเภทของข้อมูล
* ค่าทางสถิติพื้นฐาน
* การสร้าง Visualization เพื่อเห็นรูปแบบในข้อมูล
* การวัดความเหมือน–ความต่างของข้อมูล
สิ่งเหล่านี้คือแก่นสำคัญก่อนจะทำ Machine Learning, Clustering หรือ Pattern Mining ต่อไป

### 🧹 Chapter 3. Data Preprocessing
ก่อนนำข้อมูลไปใช้วิเคราะห์หรือสร้างโมเดล สิ่งสำคัญที่สุดคือ การเตรียมข้อมูล (Data Preprocessing) เนื่องจากข้อมูลในโลกจริงมักมีปัญหา เช่น ข้อมูลหาย ข้อมูลผิดพลาด หรือข้อมูลไม่สอดคล้องกัน หากนำข้อมูลเหล่านี้ไปใช้โดยตรงจะทำให้ผลลัพธ์ที่ได้ “ไม่มีคุณภาพ” ดังนั้นบทนี้จึงมุ่งเน้นการปรับปรุงคุณภาพข้อมูล
เพื่อให้พร้อมสำหรับการทำ Data Mining
🧹 Data Cleaning เป็นขั้นตอนในการแก้ไขปัญหาข้อมูล เช่น ข้อมูลหาย (Missing), ข้อมูลผิดพลาด (Noise) และข้อมูลไม่ตรงกัน มีเป้าหมายเพื่อทำให้ข้อมูล ถูกต้องและน่าเชื่อถือมากขึ้น
🔗 Data Integration เป็นการรวมข้อมูลจากหลายแหล่งเข้าด้วยกัน เช่น Database หลายระบบ โดยต้องจัดการกับปัญหา เช่น ข้อมูลซ้ำ หรือข้อมูลที่มีรูปแบบไม่เหมือนกัน
📉 Data Reduction เป็นการลดขนาดข้อมูลให้เล็กลง โดยยังคงข้อมูลสำคัญไว้ช่วยให้การประมวลผลเร็วขึ้น
และใช้ทรัพยากรน้อยลง
📊 Dimensionality Reduction เป็นการลดจำนวนตัวแปร (Feature) ในข้อมูลช่วยลดความซับซ้อนลด noise และทำให้โมเดลทำงานได้มีประสิทธิภาพมากขึ้น
⭐ Principal Component Analysis (PCA) เป็นเทคนิคสำคัญในการลดมิติข้อมูล โดยการเปลี่ยนข้อมูลไปอยู่ในแกนใหม่และเลือกเฉพาะข้อมูลที่สำคัญที่สุด

### 📊 Chapter 6. Frequent Pattern Mining
บทนี้เน้นการค้นหารูปแบบ (Pattern) ที่เกิดขึ้นบ่อยในข้อมูลเพื่อค้นหาความสัมพันธ์ที่ซ่อนอยู่เช่น พฤติกรรมการซื้อสินค้า
🔹 Pattern Discovery เป็นกระบวนการค้นหารูปแบบที่สำคัญในข้อมูลรูปแบบเหล่านี้ช่วยให้เข้าใจพฤติกรรม และสามารถนำไปใช้ตัดสินใจได้
🧩 Frequent Itemsets เป็นกลุ่มของข้อมูลที่เกิดขึ้นบ่อยโดยพิจารณาจากค่า Support ใช้เป็นพื้นฐานในการสร้างกฎความสัมพันธ์
🔗 Association Rules เป็นกฎที่แสดงความสัมพันธ์ระหว่างข้อมูล เช่น “ถ้าซื้อ A มักจะซื้อ B” ใช้วัดด้วยค่า Support และ Confidence
⚙️ Apriori Algorithm เป็นอัลกอริทึมพื้นฐานในการหา Frequent Itemsets มีแนวคิดสำคัญคือ “ถ้าชุดย่อยไม่เกิดบ่อย ชุดใหญ่ก็จะไม่เกิดบ่อย”
🌳 FP-Growth เป็นอัลกอริทึมที่พัฒนามาให้เร็วกว่า Apriori โดยไม่ต้องสร้าง candidate จำนวนมากและใช้โครงสร้าง FP-tree
📊 Pattern Evaluation เป็นการวัดว่ารูปแบบที่ได้ “น่าสนใจหรือไม่” ใช้ตัวชี้วัด เช่น Lift และ χ² เพื่อช่วยคัดกรอง Pattern ที่มีคุณค่า

### 🔗 Chapter 8. Cluster Analysis
บทนี้กล่าวถึงการจัดกลุ่มข้อมูล (Clustering) ซึ่งเป็นการเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning)โดยมีเป้าหมายเพื่อแบ่งข้อมูลออกเป็นกลุ่ม
ที่มีความ “คล้ายกันภายในกลุ่ม” และ “แตกต่างกันระหว่างกลุ่ม”
🔹 What is Clustering?
Clustering คือกระบวนการจัดกลุ่มข้อมูลโดยไม่ต้องมี label กำหนดล่วงหน้าช่วยให้ค้นพบโครงสร้างหรือรูปแบบที่ซ่อนอยู่ในข้อมูล
📏 Similarity & Distance Measures เป็นการวัดความเหมือนหรือความแตกต่างของข้อมูลเช่น Euclidean distance หรือ Manhattan distance
มีบทบาทสำคัญในการตัดสินว่าข้อมูลควรอยู่กลุ่มเดียวกันหรือไม่
⚙️ Partitioning Methods เป็นวิธีแบ่งข้อมูลออกเป็นกลุ่มแบบกำหนดจำนวนกลุ่มล่วงหน้าเช่น K-Means โดยจะพยายามให้ข้อมูลในกลุ่มเดียวกันมีความใกล้เคียงกันมากที่สุด
🌳 Hierarchical Clustering เป็นการสร้างโครงสร้างแบบลำดับชั้นของกลุ่มสามารถแบ่งเป็น:Agglomerative (รวมกลุ่ม) Divisive (แยกกลุ่ม)
เหมาะสำหรับการวิเคราะห์ความสัมพันธ์เชิงลำดับ
🧊 Density-Based Methods เป็นการจัดกลุ่มโดยพิจารณาความหนาแน่นของข้อมูลสามารถค้นหากลุ่มที่มีรูปร่างซับซ้อนได้ และสามารถแยก outlier ได้ดี
🧩 Grid-Based Methods เป็นการแบ่งพื้นที่ข้อมูลออกเป็น grid ช่วยให้การคำนวณเร็วขึ้น และเหมาะกับข้อมูลขนาดใหญ่
🎯 Evaluation of Clustering เป็นการวัดคุณภาพของการจัดกลุ่ม เช่น ความแน่นภายในกลุ่ม และความแตกต่างระหว่างกลุ่ม

### 🤖 Chapter 9. Classification: Advanced Methods
บทนี้กล่าวถึงเทคนิคการจำแนกข้อมูล (Classification) ขั้นสูงที่ใช้ในการทำนายประเภทของข้อมูลจากรูปแบบที่ซับซ้อนมากขึ้น โดยครอบคลุมโมเดลที่มีความสามารถสูง เช่น Bayesian Networks, SVM และ Neural Networks
🧠 Bayesian Belief Networks เป็นโมเดลที่ใช้หลักความน่าจะเป็นในการแสดงความสัมพันธ์ระหว่างตัวแปรในรูปแบบกราฟช่วยให้สามารถวิเคราะห์ “ความสัมพันธ์เชิงเหตุและผล” และใช้ในการทำนายความน่าจะเป็นของเหตุการณ์ต่าง ๆ ได้
⚙️ Support Vector Machines (SVM) เป็นอัลกอริทึมที่ใช้ในการจำแนกข้อมูลโดยการหาเส้นแบ่ง (Hyperplane) ที่ดีที่สุดระหว่างกลุ่มข้อมูลมีจุดเด่นคือสามารถจัดการข้อมูลที่ซับซ้อน และทำงานได้ดีทั้งแบบเชิงเส้นและไม่เชิงเส้น
🤖 Neural Networks & Deep Learning เป็นโมเดลที่เลียนแบบการทำงานของสมองมนุษย์โดยใช้โครงข่ายของ “นิวรอนเทียม” สามารถเรียนรู้รูปแบบที่ซับซ้อนมาก
และถูกใช้ในงาน เช่น ภาพ เสียง และภาษา
🧩 Pattern-Based Classification เป็นการนำ Pattern ที่ค้นพบจากข้อมูลมาใช้เป็น Feature ในการจำแนกช่วยให้โมเดลสามารถเข้าใจข้อมูลที่มีโครงสร้างซับซ้อนได้ดีขึ้นเช่น ข้อมูลแบบลำดับ หรือกราฟ
📏 Lazy Learners & K-Nearest Neighbors (KNN) เป็นวิธีที่ไม่สร้างโมเดลล่วงหน้าแต่จะใช้ข้อมูลจริงในการเปรียบเทียบตอนทำนายโดยจะดู “เพื่อนบ้านที่ใกล้ที่สุด” เพื่อใช้ตัดสินใจในการจำแนกข้อมูล
🔄 Other Classification Methods รวมเทคนิคอื่น ๆ ที่ใช้ในการจำแนกข้อมูล เช่น Rule-based classification และวิธีผสมผสานหลายโมเดล
เพื่อเพิ่มความแม่นยำของการทำนาย

### 🧠 Chapter 10: Cluster Analysis - Basic Concepts and Methods
ยินดีต้อนรับสู่คลังความรู้เรื่อง การวิเคราะห์กลุ่มข้อมูล (Cluster Analysis) ซึ่งสรุปเนื้อหาหลักจากวิชา CS 412 Intro. to Data Mining โดย Jiawei Han เนื้อหาชุดนี้จะพาคุณไปทำความเข้าใจกับหนึ่งในเทคนิคที่สำคัญที่สุดของ Unsupervised Learning 
🎯 Cluster Analysis คืออะไร?
    การวิเคราะห์คลัสเตอร์ คือกระบวนการจัดกลุ่มวัตถุข้อมูล (Data Objects) โดยมีหลักการสำคัญคือ - ความเหมือนภายในกลุ่ม (High Intra-class Similarity): ข้อมูลในกลุ่มเดียวกันต้องมีความคล้ายคลึงกันมากที่สุด - ความต่างระหว่างกลุ่ม (Low Inter-class Similarity): ข้อมูลที่อยู่คนละกลุ่มกันต้องมีความแตกต่างกันอย่างชัดเจน 

🛠 หัวข้อที่จะได้เรียนรู้ใน Repository นี้ได้แก่ 
1.Partitioning Methods: การแบ่งกลุ่มข้อมูลด้วยอัลกอริทึมยอดนิยมอย่าง K-Means และ K-Medoids 

2.Hierarchical Methods: การจัดกลุ่มแบบลำดับชั้น ทั้งแบบรวมกลุ่ม (Agglomerative) และแบบแบ่งแยก (Divisive)

3.Density-Based & Grid-Based Methods: เทคนิคการค้นหากลุ่มข้อมูลจากความหนาแน่น เช่น DBSCAN และ OPTICS เพื่อจัดการกับข้อมูลที่มีรูปร่างซับซ้อนและสัญญาณรบกวน (Noise) 

4.Evaluation of Clustering: วิธีการวัดคุณภาพและความเหมาะสมของกลุ่มข้อมูลที่สร้างขึ้น
