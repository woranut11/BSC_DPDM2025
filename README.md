## เนื้อหาที่เรียน📖
### 💡Chapter 1. Introduction (บทนำสู่ Data Mining)
ในยุคที่ข้อมูลเติบโตอย่างรวดเร็วจากระดับ *เทราไบต์ → เพตาไบต์* เรามีข้อมูลจำนวนมหาศาลจากทุกที่ เช่น ธุรกิจออนไลน์, เซ็นเซอร์, โซเชียลมีเดีย, กล้องดิจิทัล, การทดลองทางวิทยาศาสตร์ ฯลฯ แต่ปัญหาคือ
**“เรากำลังจมน้ำในข้อมูล แต่ขาดความรู้ที่นำไปใช้ได้จริง”**
เพียงมีข้อมูลเยอะไม่พอ ต้อง *แปลงข้อมูลเป็นความรู้*
นี่จึงเป็นเหตุผลที่ *Data Mining* เกิดขึ้นเพื่อช่วยให้คอมพิวเตอร์สามารถ “ค้นหารูปแบบ” หรือ “ความรู้ใหม่” จากข้อมูลขนาดใหญ่โดยอัตโนมัติ

### 🔎Chapter 2. Getting to Know Your Data (มาทำความรู้จักกับข้อมูลกันเถอะ)
ก่อนที่เราจะทำ Data Mining หรือวิเคราะห์ข้อมูลอย่างจริงจัง ขั้นตอนแรกที่สำคัญคือ *การทำความเข้าใจกับข้อมูล (Getting to Know Your Data)* เพราะข้อมูลแต่ละแบบมีคุณสมบัติไม่เหมือนกัน การเลือกใช้เทคนิควิเคราะห์จึงต้องเหมาะสมกับชนิดข้อมูลด้วย
บทนี้จึงสอนพื้นฐานสำคัญ ได้แก่
* ประเภทของข้อมูล
* ค่าทางสถิติพื้นฐาน
* การสร้าง Visualization เพื่อเห็นรูปแบบในข้อมูล
* การวัดความเหมือน–ความต่างของข้อมูล
สิ่งเหล่านี้คือแก่นสำคัญก่อนจะทำ Machine Learning, Clustering หรือ Pattern Mining ต่อไป
